# 販売ページ案

## 商品名
**アフィポ** — 商品URLから、Threadsの紹介ポストを3パターン

## キャッチコピー
- メイン: 「商品URLを貼るだけ。紹介ポストの下書きから投稿画面まで、スマホひとつで。」
- サブ: 「月額なし。1回10円から、使った分だけ。」

## 差別化ポイント（なぜアフィポか）
1. **URLから投稿画面まで1本道**
   商品ページの URL を貼ると商品名・価格・特徴を読み取り、3パターン作成 → 選んで編集 → 文章とリンクが入った Threads の投稿画面を開く、までが1画面で終わる。プロンプトをコピーして AI に貼り、結果を Threads に貼り直す手間がない。
2. **アフィリエイト投稿のための安全装置**
   【PR】などの広告表記を自動で付け、「絶対」「最安」「痩せる」など景品表示法・薬機法で問題になりやすい表現をその場で指摘。入力にない機能や口コミを AI が作らないようにし、使っていない商品を「使ってみた」と書かせない。
3. **月額なし・登録なし・設定なし**
   アカウント登録も API キーの設定も不要。買った回数に有効期限はなく、投稿しない月は0円。予約投稿ツールの月額（1,000〜2,000円台）を払うほどではない個人向け。

## 主要機能
- 商品 URL の読み取り（楽天市場ほか。読み取れないサイトは手入力）
- 投稿文を3パターン同時作成・別の案の再作成
- テンプレート（体験レビュー／悩み解決／使い方提案／お得情報／選び方・比較＋自分用を追加）
- トーン選択（カジュアル／丁寧／熱量高め／落ち着いた）
- 文章の編集・文字数カウント（Threads の 500 文字制限）
- 広告表記の自動付与・表現チェック
- リンクの位置を選択（投稿にリンクカード／リプ欄に貼る）
- Threads の投稿画面を開く・コピー
- 投稿履歴・お気に入り
- **上級者向け：自動投稿（予約投稿）**… 確認した投稿を指定日時に自動で投稿。リンクを自分の投稿へのリプとして自動で付けることもできる（ご自身の Meta アプリとの接続が必要。1件1回分。スパム判定を避けるため1日5件まで）

## 対象ユーザー
- Threads で楽天・Amazon などの商品紹介をしている、または始めたい個人
- 毎回の紹介文を考えるのに時間がかかっている人
- PC を開かずスマホだけで投稿を作りたい人
- 月額制のツールを契約するほどの投稿量ではない人

## 使い方（3ステップ）
1. 商品ページの URL を貼って「読み取る」（アフィリエイトリンクも入力）
2. テンプレートを選んで「投稿文を3パターン作る」
3. 気に入った案を選んで整え、「Threads で投稿画面を開く」→ 内容を確認して投稿

## スクリーンショット構成（縦長 6 枚）
1. 表紙: 作成画面＋「商品URLを貼るだけ。紹介ポストを3パターン」
2. URL を貼って「読み取る」→ 商品名・価格が自動で入った状態
3. 3パターンの結果カード（切り口のラベル付き）
4. 編集画面: 文字数カウント・【PR】表記・表現チェックの警告が出ている様子
5. Threads の投稿画面に文章とリンクカードが入った状態
6. 履歴・お気に入りと料金表（10回 160円／50回 480円／120回 980円・有効期限なし）

## 注意事項（販売ページに必ず載せる）
- 本アプリは投稿文の**下書き**を作るツールです。売上や報酬を保証するものではありません
- AI の文章は誤りを含むことがあります。価格・仕様は商品ページで確認してから投稿してください
- 通常の投稿は Threads の公式画面からご自身で行います。自動投稿（予約投稿）は上級者向けで、ご自身で Meta の開発者登録とアプリ作成が必要です（設定に10〜15分）
- 自動投稿を使っても、投稿内容や頻度によっては Meta によりアカウントが制限される場合があります
- アフィリエイト投稿には広告表記が必要です（アプリが自動で付けます）
- Threads・各アフィリエイトサービスの規約を守ってご利用ください
- 商品 URL の読み取りはサイトによってできない場合があります（Amazon など）。その場合は手入力してください
- 回数は端末ごとの引き継ぎコードに記録されます。機種変更前にコードを控えてください
- 「Threads」は Meta Platforms, Inc. の商標です。本アプリは Meta 社と提携・承認関係にありません
