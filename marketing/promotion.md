# 集客プラン（低コスト）

## 方針
- 「稼げる」ではなく「紹介文づくりの手間が減る」を伝える。誇張表現は使わない
- 自分自身がアフィポで作った Threads 投稿を実際に運用し、その過程（作成時間・使い方）を見せるのが最大の宣伝材料
- 宣伝投稿も Threads・X の規約に沿って、同じ文面の連投や大量投稿はしない

## チャネル別
| チャネル | やること | 費用 |
|---|---|---|
| Threads | 自分のアカウントで「アフィポで作った紹介ポスト」を日々投稿。週1〜2回、作り方や Before/After を投稿。プロフィールに販売ページのリンク | 0円 |
| X | Threads アフィリエイトの情報を発信している層に向けて、使い方の短い動画・画像を投稿。「#Threads運用」「#楽天ROOM」など関連タグ | 0円 |
| YouTube Shorts / TikTok | 画面録画 15〜30 秒：「URL を貼る → 3パターン → Threads が開く」を早送りで見せる。テロップのみで顔出し不要 | 0円 |
| Google 検索 | 販売サイト内に「Threads アフィリエイト 紹介文 例」「Threads PR 表記 やり方」「楽天 紹介文 書き方」などの解説ページを数本置く（使い方ページと同じドメイン） | 0円 |
| note | 「Threads で商品紹介するときの広告表記とNG表現まとめ」を無料記事で公開し、最後にアプリを紹介 | 0円 |

## 宣伝投稿（そのまま使える文案）

### 1. Threads（ローンチ告知）
```
商品紹介ポストを作るアプリを作りました。

商品URLを貼る
→ AIが紹介文を3パターン
→ 選んで直して
→ 文章とリンク入りでThreadsの投稿画面が開く

ここまでスマホだけで終わります。
月額なし、30回300円から。
```

### 2. Threads（悩み起点）
```
紹介ポスト、1本書くのに15分かかってた。

・商品の特徴をまとめる
・書き出しを考える
・PR表記を付ける
・リンクを貼る

これを全部まとめてやってくれるアプリを作った。
下書きが3つ出てくるから、選んで自分の言葉に直すだけ。
```

### 3. Threads（安全面）
```
アフィリエイトの投稿で気をつけてること。

・【PR】などの広告表記を付ける
・「絶対」「最安」「痩せる」は根拠がなければ使わない
・使ってない商品を「使ってみた」と書かない

自作アプリにこのチェックを全部入れた。
AIに書かせても、ここだけは人が確認するのが大事。
```

### 4. X（機能紹介・画像4枚）
```
Threads向けの商品紹介ポストを作るアプリ「アフィポ」

① 商品URLを貼る（楽天など自動読み取り）
② 3パターン作成
③ 表現チェック＋PR表記を自動で
④ Threadsの投稿画面がリンク付きで開く

登録なし・月額なし。30回300円〜
#Threads運用
```

### 5. X（開発者として）
```
個人開発でThreadsの紹介ポスト作成アプリを出しました。

こだわったところ
・月額にしない（使った分だけ、有効期限なし）
・自動投稿はしない（投稿ボタンは自分で押す）
・入力していない情報をAIに書かせない

紹介文づくりに時間がかかっている人向けです。
```

### 6. YouTube Shorts / TikTok（台本・20秒）
```
[0-3秒] テロップ「商品紹介ポスト、URLだけで作る」
[3-8秒] 楽天の商品URLを貼って「読み取る」→ 商品名と価格が入る
[8-13秒] 「3パターン作る」→ 3案が並ぶ
[13-17秒] 1つ選んで少し編集 → 【PR】と文字数が見える
[17-20秒] Threadsの投稿画面がリンク付きで開く → テロップ「月額なし・30回300円〜」
```

### 7. Threads（使い方 Tips）
```
アフィポで紹介文を作るときのコツ。

「あなたの使用感」の欄に一言でも本音を書くと、
文章が一気に自分っぽくなる。

例：「朝の満員電車でも音が気にならない」

AIはここに書いたことだけを体験談にします。
```

### 8. note 記事タイトル案（Google 検索も兼ねる）
```
Threadsで商品紹介するときの「広告表記」と「NG表現」まとめ
― ステマ規制・景表法・薬機法で気をつけるポイント
```

### 9. Threads（価格の考え方）
```
アフィポを月額にしなかった理由。

紹介ポストを作るのは、毎日の人もいれば週1の人もいる。
使わない月にもお金がかかるのは嫌だったので、
買った回数は期限なし、使った分だけにしました。

1回（3パターン）あたり8〜10円です。
```

## 最初の1か月の動き方
1. 週1: 自分の Threads でアフィポを使った紹介ポストを継続（実例を増やす）
2. 週1: 機能紹介か Tips の投稿（上の 2・3・7）
3. 週1: Shorts/TikTok 動画を1本
4. 月1: note の解説記事を1本
5. 問い合わせや要望を見て、テンプレートを追加していく
