プライバシーポリシー

制定日：2026年10月【要記入】

取得する情報

  • 端末のランダムID（引き継ぎコード）：購入した回数の管理に使います。氏名やメールアドレスとは結びつきません。
  • 文章作成のために入力した商品情報：AI での文章作成のためにサーバーを経由して Anthropic 社に送信します。当方のサーバーには保存しません。
  • 商品ページの URL：「読み取る」を使った場合、そのページの公開情報（タイトル・説明・価格・画像）を取得するために使います。保存しません。
  • Threads のアクセストークン（自動投稿を使う場合のみ）：利用者ご自身の Meta アプリで発行したトークンを暗号化して保存し、予約投稿とトークンの延長だけに使います。接続を解除すると削除します。予約した投稿の本文・リンク・日時も、投稿処理のためにサーバーに保存します。アプリシークレットは保存しません。
  • 決済情報：決済は Stripe 社が処理します。カード番号等を当方が受け取ることはありません。当方は購入日時・金額・端末IDを記録します。

端末内に保存する情報

作成した文章、履歴、お気に入り、テンプレート、入力途中の商品情報は、お使いの端末（ブラウザ）の中にだけ保存され、当方のサーバーには送信されません。

外部サービス

  • Anthropic, PBC（AI による文章作成）… API 経由で送信されたデータは、同社の規約に基づき取り扱われます。
  • Stripe, Inc.（決済）
  • Meta Platforms, Inc.（自動投稿を使う場合、Threads API を通じて投稿）
  • Cloudflare, Inc.（サーバー・配信）

利用目的

本サービスの提供、利用回数の管理、不正利用の防止、お問い合わせへの対応のために利用します。

第三者提供

法令に基づく場合を除き、本人の同意なく第三者に提供しません（上記の外部サービスへの委託を除く）。
