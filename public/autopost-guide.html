自動投稿の設定方法

自動投稿（予約投稿）は、確認済みの投稿を指定した日時に Threads へ自動で投稿する上級者向けの機能です。Threads の公式 API を、ご自身で作成した Meta アプリを通して使います。初回の設定に10〜15分ほどかかります。

Meta の画面は予告なく変わることがあります。名称が違う場合は近い項目を探してください。

1. Meta for Developers に登録する

developers.facebook.com を開き、Facebook / Meta アカウントでログインして開発者として登録します。

2. アプリを作る

「マイアプリ」→「アプリを作成」。ユースケースは「Threads API にアクセス」を選び、アプリ名（例：my-affipost）を付けて作成します。
作成したアプリの「ユースケース」→ Threads API の「カスタマイズ」で、権限 threads_basic と threads_content_publish が追加されていることを確認します（なければ追加）。

3. 自分の Threads アカウントをテスターにする

アプリの「アプリの役割」→「役割」→「メンバーを追加」→ Threads テスター に、自分の Threads のユーザー名を追加します。
Threads アプリ（または threads.com）で「設定」→「アカウント」→「ウェブサイトのアクセス許可」→「招待」を開き、届いた招待を承認します。

4. アクセストークンを発行する

アプリの Threads API ユースケースの「設定」にあるユーザートークン生成ツールで、自分のアカウントの「アクセストークンを生成」を押し、表示されたトークンをコピーします。
同じ画面の Threads アプリシークレット（「表示」を押すと見られます）もコピーしておきます。短期トークンを60日間有効なトークンに交換するために1度だけ使い、アフィポは保存しません。

5. アフィポと接続する

アフィポの「設定」→「自動投稿」→「Threads と接続する」に、アクセストークンとアプリシークレットを貼り付けて「接続する」。@ユーザー名が表示されれば完了です。
以降は「作成」画面の編集欄にある「日時を指定して自動投稿」から予約できます。予約の状態は「履歴」→「⏰ 予約」で確認・取り消しできます。

使い方のルール（スパム判定を避けるため）

  • 自動投稿は1日5件まで、前後の予約と60分以上あける必要があります
  • 同じ文章は14日間、再予約できません
  • 投稿時刻は指定から最大15分ずれます（毎日まったく同じ時刻の投稿は機械的に見えるため）
  • リンクの位置を「リプ欄に貼る」にすると、本文の投稿後に、リンク付きのリプを自分の投稿に自動で付けます
  • 予約1件につき1回分を使います。投稿前の取り消し・投稿失敗のときは回数が戻ります

Meta はリンク付きの投稿を機械的に繰り返すアカウントを制限することがあります。紹介投稿だけでなく、ふだんのつぶやきや交流も手動で行うことをおすすめします。アカウントの制限について当方は責任を負えません。

トークンについて

  • アクセストークンは暗号化してサーバーに保存し、予約投稿とトークンの延長だけに使います
  • トークンは自動で延長されます。60日以上アフィポで自動投稿をしなかった場合などに切れたときは、4〜5 をやり直してください
  • 「接続を解除」するとトークンは削除され、未投稿の予約は取り消されて回数が戻ります
  • Meta アプリ側でアプリを削除・テスターを外すと、自動投稿はできなくなります
